# CMS 2.0 – Test Plan and Results

## Automated Test Framework

Suite **"CMS 2.0 – Role Profile and Competency Library"**: 13 tests, 59 steps, server-side only, so it
runs headless through the CI/CD API. Generated by `tools/generate-atf.py` into
`src/fluent/tests/cms-atf.now.ts`.

How each test works:

* It creates its own users with CMS roles (never an existing user).
* A CMS Administrator test user builds an `ATF-*` fixture through GlideRecordSecure, so business rules
  and ACLs are exercised.
* ATF rolls everything back afterwards.

### Running the suite

ATF execution is disabled on the PDI by default (`sn_atf.runner.enabled=false`). For these runs it was
set to `true` temporarily and restored to `false` afterwards.

```bash
npm run build && npm run deploy
now-sdk cicd testsuite run --test-suite-name "CMS 2.0 – Role Profile and Competency Library"
```
